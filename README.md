# 🧠 Schul-Gehirn

Meine Berufsschul-Mappen als App – nie wieder Blätter mitschleppen.

**Öffnen:** https://stein11111.github.io/schulgehirn/

- 🗂️ Jedes Fach ist eine Mappe mit Registerkarte, darin Unterordner (Lernfelder/Themen)
- 📷 Blätter fotografieren → automatisch wie ein Scan (Schatten weg, scharf), mehrere Seiten pro Blatt
- 📄 PDFs hochladen (Text wird durchsuchbar)
- ✅ Aufgaben mit Fälligkeit, 💭 Gedanken/Notizen
- 📅 Stundenplan: zeigt den nächsten Schultag und was dafür offen ist
- 🔎 Suche über alles – auch den Text auf den Blättern
- ✨ KI liest Blätter, fasst zusammen, erkennt Hausaufgaben, beantwortet Fragen (kostenloser Gemini-Schlüssel unter *Mehr → KI*)
- 📲 Installierbar (Homescreen), läuft offline. Alle Daten bleiben lokal auf dem Gerät (IndexedDB). Backup als Datei unter *Mehr*.
